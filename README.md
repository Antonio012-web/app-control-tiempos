# ⏱️ App de Control de Tiempos

Aplicación desarrollada para mejorar los procesos de producción y optimizar
los tiempos de trabajo asignados a cada colaborador.

---

## 🎯 Problema detectado
La falta de coherencia en los tiempos estimados de los procesos generaba
desfases de horas y tiempos ociosos durante la operación.

---

## 💡 Solución propuesta
Desarrollo de una aplicación de control y medición de tiempos que:
- Registra el tiempo real de cada proceso
- Permite definir pasos de trabajo
- Documenta los recursos utilizados
- Genera reportes para análisis y toma de decisiones

---

## 🚀 Funcionalidades
- Registro de tiempos por proceso
- Definición de pasos de trabajo
- Control de tiempos reales vs estimados
- Análisis de desempeño por colaborador
- Reportes exportables

---

## 🛠 Tecnologías utilizadas
- Node.js
- SQLite
- JavaScript
- HTML / CSS
